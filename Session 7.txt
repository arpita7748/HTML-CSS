4.Make your product grid responsive: use grid-template-columns to show 3 columns on desktop, 2 columns on tablet, and 1 column on mobile screens.<br><br><em><strong>Hint:</strong> Use CSS media queries to change grid-template-columns based on screen width.</em>


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flipkart Product Grid</title>
    <style>
        
body {
    font-family: Arial, sans-serif;
    background-color: whitesmoke;
    margin: 0;
    padding: 20px;
}

h1 {
    text-align: center;
    color: blue;
}

.product-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
    margin-top: 30px;
}

.product-card {
    background-color: white;
    padding: 15px;
    text-align: center;
    border: 1px solid lightgray;
    border-radius: 8px;
}

.product-card img {
    width: 100%;
    max-width: 200px;
    height: 150px;
    object-fit: contain;
}

.product-card h3 {
    color: black;
}

.product-card p {
    color: green;
    font-weight: bold;
}

/* Tablet screen */
@media (max-width: 768px) {
    .product-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Mobile screen */
@media (max-width: 480px) {
    .product-grid {
        grid-template-columns: 1fr;
    }
}

</head>

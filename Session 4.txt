1.Create an HTML file that uses semantic tags to build a simple blog post layout with <header> for the blog title, <nav> for navigation links (Home, Explore, About), <article> for the main post content, and <footer> for copyright information.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Blog</title>
</head>
<body>

    <header>
        <h1>My Personal Blog</h1>
        <p>Welcome to my blog!</p>
    </header>

    <nav>
        <a href="#home">Home</a> |
        <a href="#explore">Explore</a> |
        <a href="#about">About</a>
    </nav>

    <main>
        <article id="home">
            <header>
                <h2>My Web Development Journey</h2>
                <p>Published on October 11, 2026</p>
            </header>

            <p>
                I am learning HTML and CSS to build beautiful websites.
                Semantic HTML helps me create meaningful and well-structured
                web pages.
            </p>
        </article>

        <section id="explore">
            <h2>Explore More</h2>
            <p>Discover more articles about programming and technology.</p>
        </section>

        <section id="about">
            <h2>About Me</h2>
            <p>I am a computer science graduate learning web development.</p>
        </section>
    </main>

    <footer>
        <p>&copy; 2026 My Personal Blog. All rights reserved.</p>
    </footer>

</body>
</html>

4.Given a non-semantic HTML snippet for a movie review (using only <div> and <span>), refactor it to use appropriate semantic tags like <header>, <nav>, <article>, and <footer> for improved accessibility and SEO.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Movie Review</title>
</head>
<body>

    <header>
        <h1>Movie Review Website</h1>
    </header>

    <nav aria-label="Main navigation">
        <a href="#home">Home</a>
        <a href="#movies">Movies</a>
        <a href="#reviews">Reviews</a>
    </nav>

    <main id="home">
        <article id="reviews">
            <header>
                <h2>Movie: 3 Idiots</h2>
                <p>Rating: 5/5</p>
            </header>

            <p>
                A funny and inspiring movie about college life,
                friendship and following your passion.
            </p>

            <footer>
                <p>Review category: Comedy and Drama</p>
            </footer>
        </article>
    </main>

    <footer>
        <p>&copy; 2026 Movie Review Website</p>
    </footer>

</body>
</html>
